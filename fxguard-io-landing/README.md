# ویترین fxguard.io (cPanel جدا)

> این پوشه **منبع ویترین عمومی https://fxguard.io** است.  
> با `cpanel-landing/` (لندینگ **kaya.fxguard.io**) قاطی نشود.

استخراج‌شده از `public_html` حساب cPanel `fxguard` در ۱۸ اوت ۲۰۲۶، سپس اصلاح جایگاه‌یابی:

- مخاطب اصلی: میز صرافی، حواله و فاینانس — نه اینباکس تبلیغاتی در برابر respond.io / Wati
- تمایز: نرخ ارز روی همان پنل واتساپ؛ دفتر مشتری مال شرکت؛ نقش، شعبه، ۲FA
- هسته بدون بستهٔ نرخ: تیم‌های دیگر می‌توانند ابر شروع را بگیرند
- کانال صادقانه: QR غیررسمی در برابر Meta Cloud API
- قیمت: Cloud Start ۴۹$ (اینباکس، بدون نرخ)، Business از ۲۴۹ با بستهٔ نرخ، Multi از ۴۹۹، لایسنس از ۴۰۰۰، Managed از ۸۰۰/ماه
- هوش مصنوعی: پاسخ اول اختیاری با کلید OpenAI — جایگزین نیرو و ۲FA نیست
- دمو: جلسه هدایت‌شده — رمز مشترک عمومی روی ویترین نیست
- حسابداری و وبسایت صرافی: محصولات جدا، استعلام جدا
- GDPR گواهی‌شده روی صفحهٔ اصلی نیست؛ DPA در `/eu/` و `/procurement`
- بسته تدارکات: `/procurement`

## آپلود

1. فایل‌ها را روی **`/home/fxguard/public_html`** بریزید (جایگزینی فایل‌های هم‌نام).
2. پوشهٔ **`.well-known/`** سرور را پاک نکنید (SSL/ACME).
3. `cpanel-landing/` این مخزن را روی fxguard.io آپلود نکنید.

بعد از آپلود: https://fxguard.io/ · `/pricing` · `/procurement` · `/live-demo` · `/eu/` · `?lang=fa`
