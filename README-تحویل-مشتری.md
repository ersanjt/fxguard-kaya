# واتساپ CRM حرفه‌ای — راهنمای تحویل و استفاده

این سند برای تحویل به مشتری و استفاده روزمره از سیستم تهیه شده است.

---

## معرفی محصول

**واتساپ CRM حرفه‌ای** یک سیستم مدیریت ارتباط با مشتری (CRM) است که از طریق واتساپ با مشتریان در ارتباط هستید. امکانات اصلی:

- **مکالمات:** مشاهده و پاسخ به چت‌های واتساپ در یک پنل یکپارچه
- **مشتریان:** لیست مشتریان و تاریخچه مکالمات هر مشتری
- **تیکت‌های داخلی:** ثبت و پیگیری درخواست‌های داخلی سازمان
- **دپارتمان‌ها و کاربران:** تعریف دپارتمان و کاربر با نقش (ادمین، مدیر، کارمند)
- **اتصال واتساپ:** راه‌اندازی و اتصال واتساپ از داخل همین داشبورد (نمایش QR و شروع Gateway)

## نصب و راه‌اندازی

### ۱. نصب وابستگی‌ها

در پوشه پروژه، هر دو بخش زیر را یک بار نصب کنید:

```bash
cd backend
npm install
```

```bash
cd gateway
npm install
```

(پوشه `gateway` فقط برای اتصال واتساپ لازم است؛ برای تست داشبورد بدون واتساپ می‌توانید فقط Backend را اجرا کنید.)

### ۲. تنظیم محیط (اختیاری)

- در `backend` اگر فایل `.env` وجود ندارد، از روی `backend/.env.example` کپی کنید و در صورت نیاز مقادیر را تغییر دهید.
- در `gateway` اگر فایل `.env` وجود ندارد، از روی `gateway/.env.example` کپی کنید.

برای اجرای سریع با تنظیمات پیش‌فرض، می‌توانید همین مرحله را رد کنید.

### ۳. اجرای سرور Backend و داشبورد

**ویندوز (PowerShell):**

```powershell
.\start-backend.ps1
```

**یا به صورت دستی:**

```bash
cd backend
node server.js
```

پس از بالا آمدن سرور، در مرورگر باز کنید:

**http://localhost:3002/dashboard.html**

### ۴. ورود به داشبورد

- **ایمیل:** `admin@company.com`
- **رمز عبور:** `Admin@123`

در اولین اجرا، در صورت نبودن کاربر ادمین، به‌صورت خودکار ساخته می‌شود.

### ۵. اتصال واتساپ (اختیاری)

1. از منوی داشبورد روی **«اتصال واتساپ»** کلیک کنید.
2. روی **«شروع Gateway واتساپ»** کلیک کنید و چند ثانیه صبر کنید.
3. QR Code نمایش داده می‌شود؛ آن را با اپ واتساپ موبایل (همان شماره‌ای که می‌خواهید با آن چت کنید) اسکن کنید.
4. پس از اتصال، مکالمات واتساپ در بخش **«مکالمات»** ظاهر می‌شوند.

برای اجرای دستی Gateway در یک ترمینال جدا (در صورت نیاز):

```bash
cd gateway
node src/index.js
```

## ساختار پروژه

| پوشه/فایل | توضیح |
|-----------|--------|
| `backend/` | سرور API و داشبورد (پورت ۳۰۰۲) |
| `gateway/` | اتصال واتساپ و ارسال/دریافت پیام (پورت ۳۰۰۱) |
| `backend/public/dashboard.html` | صفحه اصلی داشبورد |
| `start-backend.ps1` | اسکریپت راه‌اندازی Backend در ویندوز |
| `راه‌اندازی-سریع.md` | خلاصه راه‌اندازی به فارسی |

## عیب‌یابی

- **«سرور Backend پاسخ درست نمی‌دهد»:** مطمئن شوید از داخل پوشه `backend` دستور `node server.js` اجرا شده و پورت ۳۰۰۲ بسته نیست. آدرس داشبورد باید دقیقاً `http://localhost:3002/dashboard.html` باشد.
- **QR نمایش داده نمی‌شود:** ابتدا روی «شروع Gateway واتساپ» کلیک کنید؛ پس از حدود ۱۰–۲۰ ثانیه QR ظاهر می‌شود. در صورت نیاز Gateway را به‌صورت دستی با `cd gateway` و `node src/index.js` اجرا کنید.
- **پیام‌ها دریافت نمی‌شوند:** پس از اسکن QR، یک پیام تست از موبایل به همان شماره واتساپ بفرستید؛ مکالمه در بخش «مکالمات» ظاهر می‌شود.

---

## امنیت و محیط Production

- در محیط واقعی (Production) حتماً در فایل `.env` مقدار `JWT_SECRET` را به یک رشته تصادفی و قوی تغییر دهید.
- پورت‌ها و آدرس‌های Backend/Gateway را در `.env` مطابق سرور خود تنظیم کنید.
- دسترسی به داشبورد و API را فقط از طریق HTTPS و در صورت امکان با فایروال محدود کنید.
