اعلان‌های مدیر

API نوسان (Navasan)

کلید API برای دریافت نرخ لحظه‌ای، چارت ارزها و نوار قیمت. کلید رایگان از navasan.tech دریافت کنید. اگر اینجا خالی بماند، از متغیر NAVASAN_API_KEY در env سرور استفاده می‌شود.

دریافت کلید رایگان از ربات تلگرام @navasan_contact_bot

API الان چند (Alan Chand)

توکن وب‌سرویس الان‌چند برای قیمت لحظه‌ای ارز، طلا و رمزارز. هدر Authorization: Bearer. اگر خالی بماند از متغیر ALANCHAND_API_KEY در env سرور استفاده می‌شود.
