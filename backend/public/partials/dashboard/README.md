# منبع `dashboard.html`

فایل **`public/dashboard.html`** از ادغام این partialها **به ترتیب عددی** ساخته می‌شود:

| فایل | تقریباً | محتوا (خلاصه) |
|------|---------|----------------|
| `html-part-01.html` | ~۵۴۴ خط | `<!DOCTYPE>`، `<head>`، اسپرایت SVG، شروع `#app` و هدر |
| `html-part-02.html` | ~۵۴۴ | ادامهٔ layout، بخش‌های میانی UI |
| `html-part-03.html` | ~۵۴۴ | صفحات و فرم‌ها |
| `html-part-04.html` | ~۵۴۴ | ادامهٔ صفحات و مودال‌ها |
| `html-part-05.html` | ~۵۴۴ | مودال‌ها و بخش‌های پایانی بدنه |
| `html-part-06.html` | انتها | فوتر، اسکریپت‌ها، اسکریپت اینلاین کوچک |

خط اولِ `html-part-01.html` یادآوری منبع است.

## بعد از ویرایش

از پوشهٔ `backend`:

```bash
npm run build:dashboard
```

سپس `public/dashboard.html` را commit کنید.

## تقسیم معناداری بیشتر

الان اندازهٔ بخش‌ها تقریباً **مساوی** است تا ادغام ساده بماند. اگر خواستید بر اساس صفحه (مثلاً فقط مکالمات)، می‌توانید محتوا را بین همین فایل‌ها جابه‌جا کنید — به شرطی که **ترتیب اتصال DOM** حفظ شود (مثلاً مودال قبل از اسکریپت‌ها).
