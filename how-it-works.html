وضعیت سرویس‌ها

Backend API (پورت 3002) http://localhost:3002
WhatsApp Gateway (پورت 3001) http://localhost:3001

جریان کار (Flow)

  1. Gateway با کتابخانه whatsapp-web.js به واتساپ متصل می‌شود (با اسکن QR).
  2. وقتی کسی به شماره واتساپ شما پیام می‌دهد، Gateway آن را می‌گیرد و به صف RabbitMQ می‌فرستد (یا مستقیم به Backend).
  3. Backend پیام را از صف می‌خواند، مشتری را در دیتابیس پیدا/ایجاد می‌کند، مکالمه و پیام را ذخیره می‌کند.
  4. قوانین پاسخ خودکار و تخصیص به دپارتمان/کارمند اجرا می‌شوند.
  5. کارمند از داشبورد (یا API) مکالمات را می‌بیند و پاسخ می‌دهد؛ Backend پیام را در صف outgoing می‌گذارد و Gateway آن را در واتساپ ارسال می‌کند.

معماری ساده

[واتساپ] ←→ Gateway (QR + ارسال/دریافت) ↓ صف پیام (RabbitMQ) [CRM Backend] ←→ دیتابیس (PostgreSQL/SQLite) ↑ [داشبورد / API] ← لاگین، مکالمات، مشتریان، گزارش
