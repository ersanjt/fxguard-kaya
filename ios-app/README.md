# اپلیکیشن iOS صرافی کایا (Kaya CRM)

اپلیکیشن iOS حرفه‌ای برای دسترسی به پورتال CRM واتساپ از طریق آیفون و آیپد.

---

## 📥 ساخت و نصب

### پیش‌نیازها

- **Mac** با macOS
- **Xcode 15** یا بالاتر (از App Store)
- **Apple Developer Account** (برای نصب روی دستگاه واقعی)

### مراحل ساخت

1. پروژه را در Xcode باز کنید:
   - `File` → `Open` → پوشه `ios-app` را انتخاب کنید
   - فایل `KayaCRM.xcodeproj` را باز کنید

2. **Team** را تنظیم کنید:
   - در نوار کناری، پروژه `KayaCRM` را انتخاب کنید
   - تب `Signing & Capabilities` → `Team` را روی اکانت توسعه‌دهنده خود قرار دهید

3. دستگاه یا شبیه‌ساز را انتخاب کنید و `Run` (⌘R) را بزنید.

4. برای نصب روی آیفون:
   - دستگاه را با کابل وصل کنید
   - از منوی دستگاه‌ها، آیفون خود را انتخاب کنید
   - `Run` را بزنید

## ویژگی‌ها

- **ورود امن** با پشتیبانی از احراز هویت دو مرحله‌ای (TOTP)
- **تنظیم آدرس سرور** از صفحه ورود یا پروفایل
- **مکالمات واتساپ** لیست مکالمات، ارسال پیام، pull-to-refresh
- **چت داخلی سازمان** گفتگو با همکاران، ایجاد ترد جدید
- **داشبورد** خلاصه آمار مکالمات، مشتریان، تیکت‌ها و تسک‌ها
- **مشتریان** مشاهده و جستجوی لیست مشتریان
- **تیکت‌ها** مدیریت تیکت‌های داخلی
- **وظایف** لیست تسک‌ها
- **پروفایل** اطلاعات کاربر و خروج
- **پشتیبانی کامل RTL** برای زبان فارسی

## تکنولوژی‌ها

- **Swift** + **SwiftUI** - UI مدرن
- **URLSession** - ارتباط با API
- **UserDefaults** - ذخیره توکن و تنظیمات
- **Combine** - مدیریت state

---

## اتصال به سرور

به‌طور پیش‌فرض اپ به آدرس `https://kaya.fxguard.io/api/` متصل می‌شود.

**برای تغییر آدرس سرور:**
- از صفحه ورود روی آیکون تنظیمات (بالا راست) بزنید
- یا از پروفایل → «تغییر» کنار آدرس سرور
