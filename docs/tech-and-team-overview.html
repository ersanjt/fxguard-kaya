kayaCRM — Technology & Team Overview

این سند توضیح می‌دهد چطور سیستم ساخته شده، همهٔ تکنولوژی‌ها و چه متخصص‌هایی روی آن کار کرده‌اند.

۱. روش توسعه

سبک معماری

  • Backend مونولیتیک: یک اپ Node.js (Express) که API، احراز هویت، دیتابیس و سرو استاتیک را با هم اجرا می‌کند.
  • Gateway جدا: سرویس جدا برای واتساپ (whatsapp-web.js) برای scale جدا.
  • پنل وب بدون فریمورک: فرانت با Vanilla JavaScript (بدون React/Vue)، SPA با روتینگ هش.
  • اپ موبایل native: اندروید (Kotlin) و iOS (Swift/SwiftUI)؛ هر دو به همان API وصل می‌شوند.

ترکیب: سرور یکپارچه + Gateway واتساپ + فرانت ساده + اپ native.

۵. جمع‌بندی

روش توسعه: Backend مونولیتیک + Gateway جدا + پنل Vanilla JS + اپ‌های native اندروید و iOS.

متخصص‌ها: Backend، Frontend وب، Gateway/واتساپ، اندروید، iOS، UI/UX، DevOps و در صورت وجود QA و مترجم.

This document explains how the system was built, all technologies used, and which specialists worked on it.

1. Development Approach

Architecture Style

  • Monolithic Backend: A single Node.js (Express) app running API, auth, database, and static files.
  • Separate Gateway: Dedicated service for WhatsApp (whatsapp-web.js) for independent scaling.
  • Framework-free Web Panel: Frontend with Vanilla JavaScript (no React/Vue), SPA with hash routing.
  • Native Mobile Apps: Android (Kotlin) and iOS (Swift/SwiftUI), both using the same API.

Combination: unified server + WhatsApp gateway + simple frontend + native apps.
