# اسکریپت‌های ریشه

| فایل | کاربرد |
|------|--------|
| `check-i18n-keys.js` | بررسی پوشش کلیدهای `t()` در `dashboard.js` نسبت به `i18n-fa.js` — اجرا: `node scripts/check-i18n-keys.js` |
| `enable-self-serve-app.sh` | روشن کردن ثبت‌نام خودخدمت روی `crm-backend-app` (هرگز کایا) |
| `setup-server.sh` | راه‌اندازی اولیه سرور (لینوکس) |
| `deploy.sh` | دیپلوی (در صورت استفاده) |
